# EnergiaMap RN

### Mapa Interativo de Referências em Energias Renováveis do Rio Grande do Norte

O **EnergiaMap RN** é uma aplicação web desenvolvida para apresentar, de forma visual e interativa, referências demonstrativas relacionadas às energias renováveis no estado do Rio Grande do Norte.

Por meio de um mapa interativo, o projeto permite explorar pontos de referência associados às categorias de energia solar e eólica, utilizando marcadores personalizados, filtros e indicadores dinâmicos.

## Funcionalidades

- Mapa interativo com navegação geográfica.
- Marcadores personalizados para energia solar e energia eólica.
- Pop-ups com informações sobre os pontos demonstrativos.
- Filtros para visualizar os pontos por categoria energética.
- Painel de indicadores com atualização dinâmica.
- Enquadramento automático do mapa para visualizar os pontos cadastrados.
- Interface responsiva, adaptada a diferentes tamanhos de tela.

## Tecnologias utilizadas

- **HTML5:** estruturação da aplicação.
- **CSS3:** estilização e responsividade da interface.
- **JavaScript:** implementação das funcionalidades e interações.
- **Leaflet.js:** criação e manipulação do mapa interativo.
- **OpenStreetMap:** fornecimento dos dados cartográficos utilizados no mapa.

## Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto em seu computador.
3. Execute o arquivo `index.html` em um navegador.
4. Mantenha a conexão com a internet ativa para carregar os recursos externos do mapa.

## Sobre os dados apresentados

Este projeto possui finalidade demonstrativa e educacional.

Os pontos exibidos no mapa representam referências geográficas aproximadas dos municípios cadastrados no Rio Grande do Norte. Eles não indicam necessariamente a localização de instalações reais de geração de energia.

As informações são utilizadas para demonstrar recursos de visualização geográfica, categorização e interação com mapas.

## Objetivo do projeto

O EnergiaMap RN foi desenvolvido como projeto prático de aprendizagem, com o objetivo de aplicar conhecimentos de desenvolvimento Front-End, organização de código, manipulação do DOM, integração de bibliotecas externas e construção de interfaces interativas e responsivas.
